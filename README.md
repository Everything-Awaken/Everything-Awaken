# Everything Awaken

**Everything Awaken™** builds calm, private tools for a better day — made in Punjab, India, by Reet.

### Awaken Journal
A private, **end-to-end encrypted** journal app: journal, to-do, notes and personal finance on one day page. Everything you write is encrypted on your own device; we can't read it. No ads, and no AI reading your entries.

- 🌐 [everythingawaken.com/journal](https://everythingawaken.com/journal)
- 🔐 [The Awaken Journal Standard](https://everythingawaken.com/journal/standard/) — our privacy and security rules, in full
- 🧪 [awaken-journal-security](https://github.com/Everything-Awaken/awaken-journal-security) — the encryption code and test vectors, so you can check it yourself
